Our Logins

A password manager for KeePass files (.kdbx). Opens and saves the same databases as KeePass and KeePassXC, types logins into other apps with one hotkey, and unlocks with Windows Hello or Touch ID.

WindowsYour system

Download for Windows (64-bit)

Windows 10 or 11. Installs for your user only, no admin needed, with a Start menu entry. Our Logins offers each new version itself. The installer is not code-signed yet, so SmartScreen may warn: choose More info, then Run anyway.

Prefer a single program file you place yourself? OurLogins-windows-x64.exe. It cannot replace itself: accepting an update from it installs the version above alongside it.

macOSYour system

Download for Mac (Apple silicon and Intel)

macOS 12 or later. Open the .dmg and drag Our Logins to Applications. The app is not notarized yet: the first time, right-click it and choose Open. After that, Our Logins offers each new version itself.

LinuxYour system

AppImage (x86-64) .deb (Debian, Ubuntu)

AppImage: chmod +x OurLogins-linux-x86_64.AppImage, then run it. Quick unlock (fingerprint/PIN) is not available on Linux, and the typing hotkey needs an X11 session.
